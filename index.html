Featured project

SOC Analyst Home Lab

Kali, Ubuntu Server and Wazuh SIEM on VirtualBox

A personal practice environment with an attacker, a target and a SIEM on one laptop, so I can learn security monitoring without touching anyone else's systems.

What I built

  • Installed Oracle VirtualBox and created three machines on one network.
  • Kali Linux as the attacker workstation, Ubuntu Server as the target, and a Wazuh v4.14.7 appliance as the SIEM that receives logs.
  • Documented the build with addresses, steps and screenshots in the repository.

Evidence

Problems I found and what I learned

  • Kali reported receive errors on its network interface, which is common with a bridged adapter on a Wi-Fi host. I am tracking it after moving to an isolated network.
  • Bridged networking exposes the lab to my home network, so the next step is a NAT Network or Host-Only setup to contain test attacks.
  • Ubuntu had pending updates; keeping systems patched is part of the routine.
  • Snapshots make it safe to experiment and roll back.

Next steps (documented in the repo)

  • Install the Wazuh agent on Ubuntu and confirm it shows as active.
  • Run nmap scans and repeated failed SSH logins from Kali, then find the alerts in Wazuh and /var/log/auth.log.
  • Harden Ubuntu (firewall, SSH keys) and compare scan results before and after.
